Every component has a co-located `*.module.css`. Icons are 100% lucide-react, centralized in `shared/icons.tsx` + `shared/entityConstants.ts`.

## Pages (`src/pages/`)

| Page | Route | Purpose |
|---|---|---|
| `MapPage` | `/` | Imperative Leaflet map; decade timeline playback; presence/stance/kind filters; selection auto-zoom; correspondence arcs; ghost marker for selected-but-absent places. |
| `GraphPage` | `/graph` | Hand-rolled SVG force-directed claim graph (no library): pan/zoom, node-type filter, min-connections slider, Path Finder (Yen's K-shortest), Degrees-of-Separation with histogram. |
| `WikiPage` | `/wiki` | Three-column entity browser: Browse/Audit toggle, entity tabs + paginated list, center detail (relations/claims/essay/note), right `ClaimDetailPanel`; per-selection scroll memory. |
| `AuditPage` | `/audit` | Full-screen audit: filterable claim queue, full claim/evidence field dump, computed flags, review history, `DerivationChain` trails. Local widgets: `WeightBar`, `SourceTierBadge`, `AssertionBadge`, `StatusProgressBar`. |
| `GuidePage` | `/guide` | Renders `docs/user-guide.md` via react-markdown + remark-gfm (the only use of that library). |

All five pages are **mounted simultaneously** and display-toggled by pathname (`src/App.tsx:11-23`) — see [architecture.md](./architecture.md#routing) for the consequences.

## Reuse Guidance for New Features

- **Entity anywhere:** `EntityLink` + `EntityHoverWrap` + `KindIcon` — never a bare `<a>`.
- **Detail surface:** extend `EntityDetail` tabs rather than building a new panel.
- **Lists:** `usePaginatedList` + `SearchInput` + `Pagination`.
- **Claims/evidence display:** `RelationCard`/`ClaimRow` + `EvidenceCard` + `CertaintyBadge`.
- **New filters:** `Chip`/`FilterChips`/`ToggleGroup` patterns from `LeftPanel`/`AuditView`.
- **Colors:** tokens in `styles/tokens.css`; if Leaflet/inline-SVG needs the value, add to `entityConstants.ts` too (CSS vars are unreadable there — keep both in sync).
