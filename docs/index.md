## Project Overview

- **Type:** monolith, single part — web SPA (React) + embedded offline data pipeline (Python)
- **Primary language:** TypeScript 5 (strict) · Python 3.9+ (stdlib-only tooling)
- **Architecture:** component-based static SPA; all data bundled at build time from TSV; no backend/database ([details](./architecture.md))

## Quick Reference

- **Tech stack:** React 18 + Vite 5 · React Router 7 (HashRouter) · Zustand 5 · Leaflet 1.9 · CSS Modules + tokens · GitHub Pages CI
- **Entry points:** `index.html` → `src/main.tsx` → `src/App.tsx` (app) · `scripts/validate_canonical_data.py` (data pipeline)
- **Read-first files for AI agents:** `src/data/types.ts` (all domain types) · `src/data/dataStore.ts` (data access) · `docs/ui_rules.md` (UI contract) · `docs/app-data.md` (data spec)
- **Quality gates:** Python validator runs before `npm run dev` and on every commit (pre-commit hook); `tsc -b` inside build; **no code test suite**
- **Dataset scale:** 2,153 claims · 2,217 evidence links · 547 passages · 191 people · 98 places · 115 works · 25 predicates

## Getting Started

```bash
npm install     # installs deps + husky hooks
npm run dev     # validates data (Python), then serves at http://localhost:5173
```

1. **Understanding the system:** read [project-overview.md](./project-overview.md) → [architecture.md](./architecture.md) → [data-models.md](./data-models.md).
2. **Changing data:** [development-guide.md](./development-guide.md#change-or-add-data-the-primary-workflow) — edit sheets, validate, commit sheets + regenerated derived tables together.
3. **Changing UI:** [ui_rules.md](./ui_rules.md) + [component-inventory.md](./component-inventory.md).
4. **Planning new features (brownfield PRD):** feed this index to the PRD workflow; the architecture invariants section lists the constraints new work must respect.
