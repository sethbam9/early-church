# Project Overview — Early Christianity Atlas

> Generated by BMad `document-project` (deep scan) on 2026-07-01. Part of the [generated documentation set](./index.md).

## What This Is

An interactive research atlas for the geographic spread, relationships, and doctrinal history of early Christianity, **AD 33–800**. Everything the app shows is backed by a structured, evidence-graded dataset: 2,153 claims (subject→predicate→object triples) linking 191 people, 98 places, 115 works, 61 events, 41 groups, and 67 doctrinal propositions to 547 source passages, each claim carrying certainty, review state, and weighted evidence.

**Three primary surfaces** (plus two supporting ones):

| Surface | Route | What it does |
|---|---|---|
| 🗺 Map | `/` | Decade-by-decade playback of Christian presence across the ancient world; presence/kind/stance filters; correspondence arcs. |
| 🕸 Graph | `/graph` | Force-directed relationship graph with path finding and degrees-of-separation. |
| 📖 Wiki | `/wiki` | Entity browser with full claim/evidence audit trail, relation tabs, timelines, and five long-form essays. |
| 🔍 Audit | `/audit` | Claim-by-claim evidence inspector: computed quality flags, review history, derivation chains. |
| 📘 Guide | `/guide` | In-app rendering of the user guide. |

## Classification

- **Repository type:** monolith, single part
- **Project type:** web (React SPA) with an embedded offline data pipeline
- **Architecture:** component-based SPA over **build-time static data** — no backend, no database, no runtime data API ([architecture.md](./architecture.md))

## Tech Stack Summary

React 18 + TypeScript 5 (strict) on Vite 5 · React Router 7 (HashRouter) · Zustand 5 · Leaflet 1.9 · CSS Modules + design tokens (dark mode) · Python 3.9+ stdlib-only data validator · Husky pre-commit gate · GitHub Actions → GitHub Pages.

## The Dataset Is the Product

The repo's center of gravity is `data/`: 16 hand-curated TSV sheets validated by a ~30-check Python validator that also regenerates 6 derived tables (map decades, entity footprints, derived edges, first attestations, proposition presence, note mentions). A completed 176-batch audit campaign (`data/audit/`) reviewed every claim's evidence. See [data-models.md](./data-models.md) for the as-built reference and [app-data.md](./app-data.md) for the normative spec.
